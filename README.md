# Ōta Life — redesign

A design proof of concept for the Ōta TOKYO fan app: three mascots host the app, one currency (Ōra) measures everything, and every reward moves.

- `site/` — showcase page with the live app in an iPhone frame and demo buttons (deploy this folder).
- `ota-life-app/` — the React Native (Expo) Android app. `npm run build:site` exports its web build into `site/app`.
- `app/` — the first interactive HTML prototype.
- `research/` — teardown of the current app and the redesign blueprint.
- `screenshots/` — screenshots of the current app used in the teardown.
